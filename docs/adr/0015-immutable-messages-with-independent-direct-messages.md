# Keep messages immutable and independent from circles

PrayerPal will not allow users to edit or delete Circle Messages or Direct Messages. New members see Circle Messages from the date they join onward. Removing or leaving a circle removes access to the circle and its messages, but Direct Messages remain open with their history because they are separate from circle membership. When a user deactivates their account, messages remain and preserve the user's display name. The initial version provides no message moderation or blocking tools.

This keeps the two conversation types distinct and prevents message history from changing silently, but means users must rely on leaving a circle or removing a member if a message becomes harmful.
