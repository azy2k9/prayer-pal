# Start with one Hanafi timing configuration

PrayerPal will initially expose one Hanafi-oriented timing preset supplied by its prayer-times provider. Users will be able to see the location, named calculation method, Hanafi juristic-school setting, and any timing adjustments behind that preset. Expanding to other jurisprudential settings and calculation conventions is deferred until the timing boundary is specified precisely; “Hanafi” must not be treated as a complete explanation of every dawn and nightfall parameter.

This keeps the first release understandable and avoids presenting multiple religious timing choices before the product can explain their differences. The timing provider remains a replaceable boundary for future methods.
