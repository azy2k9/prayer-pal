# Track each obligatory prayer as one outcome

PrayerPal will track each daily obligatory prayer as one user-selected outcome: completed, not completed, or Qada. It will not separately track the Fard, Sunnah, or Witr components of a prayer. On Friday, Jumu'ah is tracked in place of Dhuhr and has only two outcomes: completed or not completed; Jumu'ah cannot be recorded as Qada.

This keeps the first version focused on the product's core behavior—completing the day's obligatory prayers—without making users model religious components that are outside the initial scope.
