# Make circles discoverable without making prayer activity public

Users will be able to find Prayer Circles by name and request to join, while existing members can also share a single-use invite link that expires after two days. Name-based joining requires approval; joining through an invite link is immediate after sign-in or sign-up. Circle names and member counts are discoverable; prayer completions and encouragements remain visible only after membership.

This supports family and friend groups that want to be found without turning individual prayer behavior into a public profile.
