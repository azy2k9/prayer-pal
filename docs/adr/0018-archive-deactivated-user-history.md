# Archive deactivated user history for possible return

When a user deactivates their account, PrayerPal will remove them from all circles while archiving their prayer history and rewards for possible restoration if they return. Existing Circle Messages and Direct Messages remain, preserving the user's display name. This is an account deactivation model rather than permanent erasure.

The distinction must be made clear in the product language because recoverable history has different privacy expectations from irreversible account deletion.
